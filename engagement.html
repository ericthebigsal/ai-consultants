How an engagement runs

Engagement model

Six stages, the same shape regardless of which pillar (or pillars) a client starts in. This page also carries the single running list of decisions we still owe ourselves.

01

End to end

  1. Discovery

    A conversation, not a pitch — run against the question set on Problem space & discovery.

    Produces: notes against that question set, and an honest internal read on fit against the discovery rubric.

  2. Assessment

    We go look at what's actually there — tooling, cost, code, process — specific to the pillar(s) in play, not a generic audit template.

    Produces: current-state findings, written down, that the client can sanity-check before we plan anything.

  3. Roadmap

    A prioritized plan tied to an outcome, not a list of activities.

    Produces: a written plan with sequencing, effort, and how success will be measured — agreed before build work starts.

  4. Build / Advise

    We do the work ourselves, or work alongside the client's team, depending on what the roadmap actually calls for.

    Produces: the actual deliverable — migrated workflows, a production standard, a cost dashboard, whatever the pillar calls for.

  5. Enablement

    The client's team can run it without us — that's the exit condition, not an afterthought.

    Produces: documentation, training, and a handoff plan specific to what we built or changed.

  6. Handoff

    We leave, deliberately, rather than lingering into an unstructured retainer.

    Produces: a final readout against the roadmap's success measures, and an honest note on what's still open.

02

Team model TBD

Some engagements — platform migration (Pillar 04) especially — may need an embedded engineer for hands-on coding work alongside us, not just advisory time. The WOTC migration-engineer posting referenced on Services is the clearest real-world example of this shape of work: a lead doing the migration themselves, "with support from an embedded FTE engineer for coding tasks." Whether we resource that ourselves, bring in a contractor, or ask the client to embed someone of theirs is not decided.
