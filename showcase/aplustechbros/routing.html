How it's wired

A gateway in front of every AI call. Routing is a config table, not code — each feature's tier can be changed or rolled back in seconds.

# ai-gateway routing (excerpt) content_assistant: default: mid escalate_if: # frontier only when the draft is rejected or the brief is long - draft_rejected - brief_tokens > 400 tag_classification: default: classifier-sm # fine-tuned, 20 labels fallback: mid ai_insights: default: mid calls: 1 # structured output, was 6 send_time_predictor: default: heuristic # send-history model, no LLM call

Why it's safe

  • No feature is downgraded until its eval shows the cheaper tier holds the win rate — the routing table and the eval harness ship together.
  • Every route has a fallback to the next tier up on error or low confidence.
  • The gateway logs the tier used per call, so a regression is visible in a day, not a quarter.
  • Rollback is a one-line config change, per feature.
The saving compounds. The routing change also shrinks the blast radius of the next price increase — 80% of the volume is now on cheaper, more substitutable models.
