APlusTechBros runs eight AI features across its martech platform, spends about $182k a month doing it, and can't tell you which features are worth the money. 02 · Model routing

Stop sending everything to the biggest model

Every feature calls the top frontier model regardless of the task. Classification, tag suggestion, and simple text expansion don't need it. Route each feature to the right tier and the bill drops by more than half — with quality held by the eval harness.

03 · Eval harness

Does the AI version actually win?

For each feature, a scorecard: win rate against the deterministic baseline, cost per call, and a verdict. Two features lose to a simple rules-based version — they're cut. Three more get downgraded to a cheaper model with no measurable quality loss.

04 · Prompt & call diet

4,240 tokens of instructions nobody reads

One feature's system prompt has accumulated stale few-shot examples, redundant guardrails, and formatting rules that duplicate the output schema — re-sent uncached on every one of 8 million calls a month. Trim it, cache it, and collapse the 6-call insights panel to 1.

Content-assistant system prompt 4,240 tok→680 tok−84% Eval win rate unchanged. Input cost per call down ~78% with caching.
