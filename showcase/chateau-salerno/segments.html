This is the same segment object the rest of the platform already uses. The campaign builder, journeys, and exports all consume it unchanged. The model wrote the filter — it didn't invent a new kind of segment.

In a build

  • The model maps language onto the existing filter schema. There's no new query language for anyone to learn, and no filter it can produce that a person couldn't have built by hand.
  • An ambiguous ask ("recent buyers") returns a clarifying question — "recent meaning last 30, 60, or 90 days?" — not a guess.
  • Every generated segment is saved as a normal, editable segment, with the original prompt kept on it so the next person can see the intent.
